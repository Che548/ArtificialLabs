# Переменные окружения

Реестр классифицирует параметры клиента, серверной части, инфраструктуры и испытаний. Источниками истины являются отслеживаемые файлы `.env.example`, рабочие процессы и обращения `process.env`. Действующие секреты в документацию не включаются.


> [!summary] Кратко
> Сначала определите класс переменной: публичная клиентская, серверная, инфраструктурная или испытательная. Значения `EXPO_PUBLIC_*` видны клиенту, поэтому секреты с таким префиксом запрещены.

## Классы

| Класс | Место хранения | Доступен клиенту | Допустим в Git |
|---|---|---:|---:|
| `EXPO_PUBLIC_*` | `.env.local` и параметры сборки | Да | Только безопасный пример |
| Convex CLI | локальное окружение или защищённый секрет CI | Нет | Нет |
| Среда выполнения Convex | окружение развёртывания | Нет | Нет |
| Docker Compose | локальное окружение узла | Обычно нет | Только шаблон |
| E2E | окружение процесса и игнорируемые каталоги | По префиксу | Без реквизитов и файлов |

> [!warning]
> Значение с префиксом `EXPO_PUBLIC_` попадает в клиентский пакет. Секреты с таким префиксом запрещены.

## Клиент Expo

| Переменная | Назначение |
|---|---|
| `EXPO_PUBLIC_CONVEX_URL` | адрес серверной части Convex |
| `EXPO_PUBLIC_CONVEX_SITE_URL` | адрес HTTP-действий и прокси сайта |
| `NEXT_PUBLIC_CONVEX_URL` | публичный адрес статической административной консоли; не является секретом |
| `EXPO_PUBLIC_ENABLE_STRIPCV_TEST_MODE` | локальный испытательный режим StripCV; запрещён в выпуске |
| `EXPO_PUBLIC_E2E_MODE` | нативные средства сквозных испытаний |
| `EXPO_PUBLIC_E2E_EMAIL` | адрес одноразовой тестовой учётной записи |
| `EXPO_PUBLIC_E2E_IOS_CONVEX_URL` | локальный TLS-прокси симулятора iOS |
| `EXPO_PUBLIC_E2E_ANDROID_CONVEX_URL` | обратный прокси эмулятора Android |
| `EXPO_PUBLIC_E2E_*_FIXTURE_*_URI` | временные адреса файлов сканирования, документа и импорта |

## Convex CLI и аутентификация

| Переменная | Назначение | Секрет |
|---|---|---:|
| `CONVEX_SELF_HOSTED_URL` | целевое выделенное развёртывание | Нет |
| `CONVEX_SELF_HOSTED_ADMIN_KEY` | административный доступ CLI | Да |
| `CONVEX_SITE_URL` | адрес издателя в настройке аутентификации | Нет |
| `JWT_PRIVATE_KEY` | подпись токенов | Да |
| `JWKS` | набор ключей аутентификации | Да |
| `SEED_SECRET` | защита операции начального заполнения | Да |
| `CALIBRATION_SIGNING_PRIVATE_KEY` | подпись манифестов калибровок | Да |
| `CALIBRATION_PUBLIC_KEY_VERSION` | версия публикуемого открытого ключа | Нет |
| `ANALYTICS_HASH_SECRET` | ежедневный HMAC активности | Да |

`JWT_PRIVATE_KEY`, `JWKS`, `CALIBRATION_SIGNING_PRIVATE_KEY` и `ANALYTICS_HASH_SECRET` задаются в окружении Convex. Административный ключ допускается только в игнорируемом `.env.local` и защищённом секрете GitHub Actions.

`CALIBRATION_SIGNING_PRIVATE_KEY` и `ANALYTICS_HASH_SECRET` запрещено объявлять как `EXPO_PUBLIC_*` или `NEXT_PUBLIC_*`, передавать в аргументах сборки Docker и выводить в журналы.

## Отложенные функции ИИ

| Переменная | Назначение | Исходное состояние |
|---|---|---|
| `AI_CHAT_ENABLED` | разрешение диалога | выключено |
| `AI_AGENT_ENABLED` | разрешение помощника | выключено |
| `AI_AGENT_AUTOMATION_ENABLED` | отдельное разрешение автоматизации | выключено |
| `YANDEX_AI_API_KEY` | реквизит поставщика | отсутствует |
| `YANDEX_AI_FOLDER_ID` | каталог поставщика | отсутствует |
| `YANDEX_AI_MODEL` | выбранная модель | определяется настройкой |

Наличие значений не отменяет требования к согласиям и не переводит функцию в поддерживаемый продукт автоматически.

## Инфраструктура Convex

`infra/convex/.env.example` содержит `INSTANCE_NAME`, `INSTANCE_SECRET`, `CONVEX_CLOUD_ORIGIN`, `CONVEX_SITE_ORIGIN`, `NEXT_PUBLIC_DEPLOYMENT_URL`, `PORT`, `SITE_PROXY_PORT`, `DASHBOARD_PORT`, `CONVEX_BACKEND_IMAGE` и `CONVEX_DASHBOARD_IMAGE`.

`INSTANCE_SECRET` является секретом. Образы закреплены по дайджесту; изменение дайджеста требует проверки заметок выпуска и известной предыдущей версии.

## Веб-сервер и StripCV

| Переменная | Назначение |
|---|---|
| `WEB_IMAGE` | образ производственного веб-контейнера |
| `WEB_PORT` | порт контейнера на узле |
| `DIST_DIR` | каталог статического экспорта |
| `HOST` | адрес привязки; по умолчанию локальный интерфейс |
| `PORT` | порт локального сервера |
| `STRIPCV_CLI` | путь к собранной программе StripCV |
| `OPENCV_DIR`, `CMAKE_PREFIX_PATH` | поиск OpenCV для CMake |

`HOST=0.0.0.0` не используется без осознанной необходимости: локальный интерфейс StripCV не рассчитан на публичный доступ.

## Нативные E2E

Основные настройки: `E2E_IOS_DEVICE`, `E2E_ANDROID_DEVICE`, `E2E_ANDROID_AVD`, `E2E_SEQUENTIAL_SIMULATORS`, `E2E_METRO_PORT`, `E2E_CONVEX_PROXY_PORT`, `E2E_CONVEX_SITE_PROXY_PORT`, `E2E_CONVEX_IOS_PROXY_PORT`, `E2E_RUN_ID`, `E2E_EMAIL`, `E2E_PASSWORD`, `E2E_REPORT_DIR`, `E2E_SCAN_FIXTURE_SOURCE`, `MAESTRO_BIN_DIR`, `MAESTRO_DEBUG_ROOT` и `MAESTRO_DRIVER_STARTUP_TIMEOUT`.

Контрактные ожидания задаются через `E2E_EXPECT_SCAN_COUNT`, `E2E_EXPECT_PRODUCT_DATA`, `E2E_EXPECT_OFFLINE_RECORD` и `E2E_SNAPSHOT_TIMEOUT_MS`. TLS-прокси получает временные `E2E_CONVEX_TLS_CERT` и `E2E_CONVEX_TLS_KEY`.

Исполнитель удаляет одноразовые учётные записи, сертификаты и тестовые файлы. Артефакты остаются в игнорируемых каталогах.

## Проверка перед запуском

1. Скопировать `.env.example` в `.env.local`.
2. Заменить шаблонные значения только локально.
3. Проверить `git check-ignore .env.local`.
4. Не выводить окружение целиком.
5. Перед развёртыванием отдельно подтвердить адрес назначения.
6. В выпуске проверить отсутствие испытательных флагов.
7. Выполнить соответствующую приёмочную проверку.
