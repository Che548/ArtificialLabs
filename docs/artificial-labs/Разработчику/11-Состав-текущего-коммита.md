# Состав документируемого коммита

Vault описывает только файлы, существующие в зафиксированном состоянии Git. Текущая опорная версия — `80c41c1df9a42b2b7d53caafdb193e44e8b71446` в ветке `main`.

> [!important] Граница состава
> Изменённый или неотслеживаемый файл рабочего дерева не считается частью документируемого продукта. Его содержимое нельзя использовать как подтверждение функции, пока оно не вошло в выбранный коммит.

Предыдущая документированная версия — `7380fee52cc38be3ea460c72ad972b014b3fa5ff`. До текущего `HEAD` добавлено пять коммитов:

## Новое пользовательское поведение

Текущий коммит добавляет или завершает следующие связи интерфейса:

- главная панель выбирается по цели профиля: планирование или беременность;
- календарь использует записи менструации из дневника и параметры профиля;
- прогноз цикла показывает расчётный день, окно фертильности и задержку как ориентир, а не диагноз;
- экран показателей группирует отмеченные дни менструации и их выбранную интенсивность;
- дневник считает заполненные категории за конкретный календарный день;
- взаимоисключающие варианты дневника обрабатываются единообразно;
- план показывает число действующих и завершённых пунктов и последнюю дату;
- данные профиля, анализов, сканов и плана входят в разрешённый контекст помощника;
- состояние фоновой проверки плана хранится и отображается согласованно.

Подробности находятся в [[Пользователю/02-Основные-сценарии|руководстве по дневнику]], [[Пользователю/14-Профиль-здоровья|профиле здоровья]] и [[Разработчику/25-План-наблюдения-и-рекомендации|техническом описании плана]].

## Новые детерминированные вычисления

В `lib/` добавлены четыре модуля без сетевых вызовов:

- `cycle-insights.ts` строит историю и расчётный прогноз цикла;
- `health-insights.ts` группирует последовательные записи менструации;
- `journal-options.ts` обрабатывает множественный и взаимоисключающий выбор;
- `product-insights.ts` вычисляет панель по цели, неделю беременности, заполненность дневника и прогресс плана.

Для них добавлены модульные испытания. Все четыре набора входят в `npm test`.

## Изменения плана наблюдения

`convex/agentPlan.ts`, `convex/ai/yandexProvider.ts` и `convex/aiAgentConfig.ts` теперь:

- отклоняют или повторно запрашивают неполный структурированный ответ;
- при невозможности получить пригодный ответ формируют ограниченный план из серверного каталога;
- не используют свободный вывод модели как произвольное назначение;
- разделяют пользовательские квоты интерактивного и фонового запуска;
- сохраняют общую системную квоту для защиты поставщика и бюджета.

Резервный план обеспечивает технически допустимую структуру, но не подтверждает медицинскую корректность. ИИ-функции по-прежнему выключены по умолчанию и требуют отдельного допуска.

## Допустимые источники документации

- `git show HEAD:<path>` для содержимого файла;
- `git ls-tree -r HEAD` и `git ls-files` для состава;
- испытания и конфигурация, вошедшие в тот же коммит;
- обязательные ограничения `AGENTS.md`;
- публичный контракт `README.md`.

При расхождении между рабочим файлом и коммитом используется содержимое `HEAD`.

## Что исключено

В документацию функций не входят:

- неотслеживаемые каталоги и файлы;
- незакоммиченные изменения отслеживаемых файлов;
- удалённые устаревшие материалы;
- локальная конфигурация `.obsidian/`;
- каталоги сборки и временные артефакты;
- медицинские тестовые изображения;
- локальные эксперименты и сохранённые альтернативные реализации;
- отложенная функция как обещание доступности.

## Локальный Vault

`/docs/artificial-labs/` исключён правилом корневого `.gitignore`. Заметки нельзя принудительно добавлять в индекс, фиксировать или публиковать в GitHub. В репозитории остаётся только правило исключения.

## Проверка границы

```bash
git rev-parse HEAD
git status --short --branch
git diff --cached --stat
git check-ignore -v docs/artificial-labs/00-Стартовая-страница.md
git ls-files docs/artificial-labs
```

Ожидаемый `HEAD` — полный SHA `80c41c1df9a42b2b7d53caafdb193e44e8b71446`. Последняя команда должна вернуть пустой результат: файлы Vault не отслеживаются.
