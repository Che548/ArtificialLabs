# Локальный веб-адаптер StripCV

`scripts/web-server.mjs` обслуживает локальный экспорт Expo и передаёт проверенный RGB-запрос программе `stripcv_cli`. Адаптер предназначен для разработки и проверок, а не для производственной записи медицинских данных.

По умолчанию сервер слушает `127.0.0.1:8080`. Расширять `HOST` следует только для осознанной проверки в локальной сети.

## Программный интерфейс

`POST /api/strip-cv` принимает `Content-Type: application/json`. Запрос содержит положительные целые ширину и высоту, допустимый шаг строки, RGB в Base64, профиль теста, необязательный профиль карточки и объект параметров.

## Ограничения

- тело запроса — не более 32 МиБ;
- ширина и высота — не более 32768;
- шаг строки — не более 131072;
- стандартный вывод — не более 8 МиБ;
- поток ошибок — не более 64 КиБ;
- время процесса — не более 30 секунд;
- одновременно выполняются не более двух помощников.

## Ответы

| Код | Значение |
|---:|---|
| 200 | результат JSON |
| 415 | неверный тип содержимого |
| 429 | все помощники заняты |
| 503 | программа анализа отсутствует |
| 422 | запрос или анализ отклонён |
| 405 | метод не поддерживается |

Внешний ответ не раскрывает необработанный поток ошибок программы.

## Безопасность процесса

Программа запускается без оболочки, проверенный JSON передаётся через стандартный ввод, объём вывода ограничивается, а превышение времени завершает процесс. Путь статического файла проходит нормализацию и проверку принадлежности корню.

## Статические файлы

`index.html` не кэшируется; ресурсы получают длительное неизменяемое кэширование. Заголовок `X-Content-Type-Options` равен `nosniff`. Для отсутствующего маршрута возвращается `index.html`.

## Проверка

```bash
npm run build:web
npm run build:strip-cv
npm run web:serve
npm run test:strip-cv-server
```
