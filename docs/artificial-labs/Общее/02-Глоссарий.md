# Термины и сокращения

## Терминология и карта первичных источников

| Термин | Значение в проекте |
| --- | --- |
| Локальный приоритет | Запись фиксируется на устройстве до сетевой репликации |
| Outbox | Устойчивая очередь версий для отправки |
| ACK | Подтверждение конкретной отправленной версии |
| Снимок | Представление серверных или локальных сущностей |
| Tombstone | Сохраняемая отметка удаления deletedAt |
| Opt-in | Явное разрешение пользователя на определённую возможность |
| HMAC | Криптографический код проверки с серверным секретом |
| Continuation | Ограниченное по сроку и шагу продолжение ИИ-запроса |
| RuntimeVersion | Граница совместимости нативного состава и OTA |
| SLI и SLO | Измеряемый показатель и утверждённая цель качества |
| RPO и RTO | Допустимая потеря по времени и целевое время восстановления |

Первичные источники архитектуры — package.json, app.json, app/_layout.tsx, lib/health-types.ts, lib/local-database.native.ts, lib/cloud-sync.ts и convex/schema.ts. Проверки полномочий находятся в convex/lib/access.ts и convex/lib/adminAccess.ts. Отдельные ссылки в конце глав указывают файлы, в которых раскрывается описанный контракт; пути отсчитываются от корня репозитория.

Для новых пользовательских сценариев существенны docs/chat-agent-wiring.md, docs/registration-consent.md, docs/profile-contacts.md, docs/document-ocr.md, docs/document-structure.md, docs/today-content.md и docs/agent-trigger-sync.md. Эти материалы уточняют изменения, которые не полностью отражены в ранних тематических руководствах.

Выпуск и инфраструктура определяются AGENTS.md, Dockerfile, .github/workflows/ghcr-publish.yml, .github/workflows/ota.yml, .github/workflows/e2e-live.yml и каталогами infra/convex, infra/web, infra/updates. Набор запускаемых проверок следует читать из scripts текущего package.json, поскольку состав агрегатов меняется.
