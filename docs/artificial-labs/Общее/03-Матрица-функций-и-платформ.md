# Поддержка функций по платформам

ArtificialLabs содержит три разные среды: нативное пользовательское приложение, безопасную веб-демонстрацию Expo и отдельную административную консоль. Их возможности нельзя смешивать.

| Возможность | Нативные iOS и Android | Expo Go и Expo Web | Административная консоль |
|---|---|---|---|
| Учётная запись пользователя | Да | не является поддерживаемым пользовательским режимом | только вход администратора |
| Профиль и программы | Да | демонстрация без рабочей записи | медицинский профиль недоступен |
| Дневник и календарь | Да, локально | без рабочей медицинской записи | нет |
| Прогноз цикла и графики | Да, по локальным данным | только демонстрационное представление | нет |
| SQLCipher | Да | нет | нет |
| Камера и выбор изображения | Да | не поддерживается как медицинский сценарий | нет |
| StripCV | нативная обработка | локальный адаптер только для разработки | управление неперсональным каталогом калибровок |
| Анализы и документы | структурированные записи и локальные файлы | без рабочей записи | только каталоги и опубликованные материалы |
| План наблюдения | локальный план; ИИ-проверка выключена по умолчанию | не является рабочей функцией | нет доступа к пользовательскому плану |
| Локальные уведомления | Да | нет | нет |
| Удалённые уведомления | после настройки EAS, APNs или FCM | нет | нет |
| Облачная синхронизация | после отдельного включения устройства | нет | нет |
| Подробная техническая аналитика | после отдельного согласия | веб-адаптер ничего не отправляет | только ограниченные агрегаты и ошибки |
| Каталог, партии, материалы и калибровки | загрузка удалённого каталога в клиент ещё не интегрирована | нет | Да, с серверной ролью `admin` |
| Наблюдение и административный аудит | нет | нет | Да, с серверной ролью `admin` |
| ИИ-диалог и помощник | подготовлены, но не входят в гарантированный контракт | не являются рабочей функцией | не получает медицинский контекст |

## Как читать матрицу

Expo Web и публикуемая административная консоль — разные приложения. Наличие элемента интерфейса, серверной таблицы или экспортируемой функции Convex не означает, что возможность поддерживается пользователем на конкретной платформе.

Отложенная функция остаётся отложенной, даже если код собран и виден в интерфейсе. Для поддержки нужны включённая конфигурация, разрешённая среда, испытания и пользовательский контракт.

## Как проверять платформы

- SQLCipher, камера, StripCV, SecureStore и локальные уведомления проверяются в нативной сборке разработки или выпуска.
- Expo Go не заменяет нативную сборку после изменения плагина или модуля.
- Expo Web проверяет только безопасный режим разработки без медицинской записи.
- Административная консоль собирается в `admin/out` и проверяется отдельно: вход, серверная роль, Playwright и `/health`.
