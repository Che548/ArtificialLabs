# Назначение и границы продукта

ArtificialLabs — локально ориентированное приложение для ведения сведений о менструальном цикле, подготовке к беременности и наблюдении во время беременности. Оно объединяет дневник, календарь, результаты исследований, домашние тесты, документы, напоминания и предварительный план наблюдения.

> [!warning] Не медицинское изделие
> Приложение помогает упорядочить сведения, но не ставит диагноз, не подтверждает овуляцию или беременность и не назначает лечение. Любой результат StripCV, прогноз цикла или автоматически сформированный план требует критической проверки пользователем и, когда это необходимо, медицинским специалистом.

## Для кого предназначено приложение

Основной пользователь ведёт собственные записи на личном устройстве. У него может быть одна из трёх целей профиля:

- наблюдение за циклом;
- планирование беременности;
- наблюдение во время беременности.

Отдельная роль администратора относится только к служебной веб-консоли. Она не предоставляет доступ к учётным записям, дневнику, результатам, изображениям, документам или переписке пользователей.

## Поддерживаемые нативные возможности

В отслеживаемом составе iOS- и Android-приложений реализованы:

| Область | Возможности |
|---|---|
| Доступ | регистрация по электронной почте, вход по паролю и начальная настройка профиля |
| Ежедневные записи | настроение, энергия, симптомы, питание, активность, измерения и сведения цикла |
| Календарь | фактические отметки менструации, ориентировочный прогноз цикла и показатели истории |
| План наблюдения | текущие, предстоящие и завершённые пункты с прогрессом и сроками |
| Анализы | ручной ввод, статусы результатов, прикрепление локального изображения или документа |
| Домашние тесты | камера или выбор изображения, локальная обработка StripCV, ручная коррекция и подтверждение |
| Профиль здоровья | состояния, препараты, аллергии, параметры цикла и беременности |
| Напоминания | локальное расписание; удалённая доставка только при наличии инфраструктурных реквизитов |
| Перенос | импорт и экспорт структурированных JSON- и CSV-данных |
| Синхронизация | необязательная передача разрешённых структурированных данных в Convex |
| Аналитика | ограниченные технические события по отдельному согласию |

## Принципы работы с данными

1. Нативная медицинская запись сначала сохраняется в зашифрованной базе на устройстве.
2. Облачная синхронизация включается отдельно на каждом устройстве.
3. Фотографии тестов и исходные документы остаются в каталоге приложения и не передаются в Convex.
4. Сервер получает только разрешённые структурированные сведения и проверяет их владельца.
5. Отсутствие сети не отменяет завершённую локальную запись.
6. Экспорт и облачная синхронизация не являются полной резервной копией устройства.

## Прогнозы и план наблюдения

Календарные показатели вычисляются детерминированно из дат, сохранённых пользователем. При недостатке истории приложение может использовать параметры профиля и техническое значение цикла по умолчанию. Такой прогноз не подтверждает физиологическое событие и не подходит для медицинского решения или контрацепции.

План наблюдения показывает элементы серверного каталога, их состояние и ориентировочный срок. ИИ-проверка плана подготовлена в коде, но выключена по умолчанию и остаётся отложенной функцией. Даже резервный план из встроенного каталога подтверждает только допустимую структуру, а не медицинскую необходимость.

## Платформенные границы

| Платформа | Роль |
|---|---|
| iOS и Android | полный пользовательский сценарий с локальной БД, файлами, камерой и уведомлениями |
| Expo Web | демонстрация интерфейса без сохранения медицинских данных |
| `admin/` | отдельная защищённая веб-консоль для каталогов, калибровок, публикаций, обезличенных агрегатов и администраторов |

SQLCipher, SecureStore, камера, StripCV и локальные уведомления требуют нативной сборки для разработки или выпуска. Expo Go не подтверждает эти возможности.

## Отложенные или зависимые возможности

Следующие возможности не входят в безусловное текущее обещание продукта:

- подтверждение электронной почты;
- самостоятельный сброс пароля;
- распознавание текста медицинских документов;
- интеграция с Apple HealthKit или Android Health Connect;
- рабочий допуск обычного ИИ-диалога, помощника и автоматической проверки плана;
- автоматизация проверки физических условий камеры;
- удалённые уведомления без EAS `projectId` и действующих реквизитов APNs или FCM.

Наличие кода, серверного переключателя или видимого элемента интерфейса не означает готовность к выпуску. Статус определяется матрицей покрытия, приёмочными проверками и решением владельцев продукта, безопасности, качества и эксплуатации.

## Административная граница

Административная консоль управляет только каталогами, партиями, калибровками, опубликованными материалами, обезличенными агрегатами, эксплуатационными проверками и правами администраторов. Каждая операция повторно проверяет роль на сервере. Медицинские таблицы пользователей не входят в допустимый контракт консоли.
