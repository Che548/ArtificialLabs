# Синхронизация и работа без сети

Синхронизация переносит структурированные записи между устройством и сервером. Она является необязательной и включается отдельно для каждого устройства.


> [!summary] Кратко
> Вход в учётную запись не включает синхронизацию автоматически. Без сети запись сохраняется локально, а исходные фотографии и документы никогда не входят в облачный обмен.

## Включение

Откройте «Профиль» → «Разрешения и данные», прочитайте описание и явно включите облачную синхронизацию. Сам факт входа в учётную запись не считается согласием.

## Передаваемые данные

Передаются профиль, дневник, лабораторные показатели, подтверждённые результаты сканирования, напоминания и метаданные документов. Фотографии тестов, исходные документы, содержимое файлов и локальные адреса не передаются.

## Состояния

| Состояние | Значение |
|---|---|
| «Синхронизация» | выполняется передача изменений |
| «Нет сети» | очередь ожидает восстановления соединения |
| «Ошибка» | серверный обмен не завершён; локальные записи должны сохраниться |
| «Данные синхронизированы» | текущая очередь обработана |

## Работа без сети

Создавайте и изменяйте записи обычным способом. Завершённое сохранение выполняется на устройстве. После возвращения сети приложение запускает повторную передачу, если синхронизация разрешена.

## Отключение

Отключение прекращает дальнейший обмен с этого устройства, но не удаляет локальные записи и не равнозначно удалению учётной записи. Ранее переданные серверные сведения удаляются только предусмотренным для этого способом.

## Если запись пропала

Не переустанавливайте приложение и не очищайте его данные. Зафиксируйте время, экран и последовательность действий, затем обратитесь в поддержку.
