# Диагностика по сценарию

Сведения о версии находятся в нижней части профиля. Три нажатия за две секунды открывают локальную диагностику. Она предназначена для агрегированных сведений о приложении, устройстве и обновлении.

При проблеме записи проверьте, появился ли объект в локальном списке. При проблеме синхронизации проверьте связь и выбранный режим. При проблеме документа определите, завершён ли импорт и есть ли готовые страницы. При проблеме уведомления различайте разрешение ОС и удалённую регистрацию.

Запишите app/build/commit/update, платформу, время и безопасный код. Не копируйте пути, значения анализов, документы или содержимое переписки. Проверка целостности локальной базы запускается только явным действием; очистка и ремонт не должны выполняться автоматически ради смены статуса.

Выбор Production или Preview меняет канал подходящих обновлений. Он не устанавливает произвольный нативный модуль и не отменяет требования совместимого runtime. Для обычной работы используется production; проверочную смену канала следует связывать с конкретным выпуском.
