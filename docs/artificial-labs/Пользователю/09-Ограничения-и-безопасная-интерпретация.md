# Ограничения и смысл подтверждения данных

Пользовательские записи, календарные расчёты и ответы чата имеют разное происхождение. Наличие значения в интерфейсе не подтверждает его правильность. Для лабораторного результата ручное подтверждение означает, что вы проверили перенос конкретных строк и дату; оно не присваивает им медицинскую норму.

Обработка документа может неверно определить раздел, единицу либо дату. Сравните результат с оригиналом. Напечатанное заключение остаётся текстом источника; объяснение модели является отдельным ответом. Не смешивайте эти два текста при проверке.

Приложение помогает организовать информацию и подготовить вопросы специалисту. Оно не обеспечивает наблюдение в реальном времени и не контролирует срочные состояния. Календарный прогноз нельзя считать подтверждённым событием только из-за точной даты на экране.
