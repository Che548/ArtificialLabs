# Техническая аналитика и дневная активность

Подробные технические события имеют отдельную настройку. Они предназначены для ограниченных статусов работы приложения; медицинские значения, тексты документов, сообщения, ключи и токены не должны входить в такие события.

Дневная активность учитывается отдельным серверным механизмом с меняющимся суточным HMAC-идентификатором. Выключение подробной аналитики не тождественно отключению этого счётчика. Поэтому корректное описание приватности различает эти назначения; слово «анонимная» само по себе не объясняет способ обработки.

Согласие на облачную синхронизацию не включает подробную аналитику автоматически. При отзыве настройки передача новых подробных событий прекращается; ранее принятые данные удаляются по соответствующему сроку хранения. Сводные счётчики могут храниться дольше отдельных технических событий.
