# Статусы операций

| Состояние | Значение | Действие |
|---|---|---|
| Сохранено локально | Запись зафиксирована на устройстве | Продолжить работу |
| Ожидает синхронизации | Передача ещё не подтверждена | Проверить связь и разрешение |
| Требуется вход | Учётные данные недоступны или отклонены | Восстановить вход |
| Функция недоступна | Нет нужной конфигурации либо допуска | Прочитать причину в настройке |
| Документ в очереди | Оригинал сохранён, обработка ожидает условий | Оставить приложение активным при связи |
| Нужен явный повтор | Исход отправленной страницы неизвестен | Решить, повторять ли обработку |
| Требуется проверка | Получен черновик | Сопоставить строки с оригиналом |
| Локальные уведомления | Удалённый канал не подтверждён | Использовать доступное расписание |

Статус относится к конкретной операции. Ошибка сервера не означает отмену локальной записи; успешная обработка текста не означает проверку всех показателей. При обращении в поддержку сохраните безопасный код и сведения о версии без содержимого данных.
