# Экспорт, импорт и удаление данных

Раздел помогает выбрать правильное действие для переноса или удаления сведений. Отключение синхронизации, выход, очистка устройства и удаление учётной записи решают разные задачи и не заменяют друг друга.

> [!summary] Перед необратимым действием
> Подготовьте JSON-экспорт, отдельно сохраните нужные фотографии и документы, проверьте полученные файлы и только затем очищайте устройство или запрашивайте удаление учётной записи.

## Какое действие выбрать

| Цель | Действие | Что сохранится |
|---|---|---|
| Перенести структурированные записи | экспорт JSON, затем импорт на новом устройстве | исходные фотографии и документы нужно переносить отдельно |
| Получить одну категорию для просмотра | экспорт CSV | остальные категории и исходные файлы в CSV не входят |
| Прекратить дальнейшую облачную синхронизацию | выключить синхронизацию | локальные данные и ранее синхронизированная серверная копия сохраняются |
| Удалить медицинские данные с текущего устройства | «Удалить локальные данные» | учётная запись, серверные данные и внешние экспорты сохраняются |
| Завершить сеанс | выйти из учётной записи | выход сам по себе не удаляет локальные и серверные сведения |
| Удалить план и автоматические правила помощника | отдельная команда удаления данных помощника | дневник, анализы, документы, сканы и обычные чаты сохраняются |
| Удалить серверную учётную запись | запросить удаление аккаунта | в течение 30 дней доступно восстановление; локальные и внешние копии управляются отдельно |

## Экспорт JSON

1. Откройте «Профиль» → «Экспорт данных».
2. Выберите JSON.
3. Подготовьте архив.
4. Сохраните файл через системное меню в защищённое место.
5. Откройте сохранённый файл или проверьте его размер до удаления исходных данных.

JSON содержит поддерживаемый набор структурированных сведений: профиль, программы наблюдения, дневник, результаты анализов и сканирований, напоминания, состояния здоровья, препараты, аллергии, метаданные документов, диалоги и настройки. Это основной переносимый архив, но не полная копия каждого объекта приложения.

В JSON не входят:

- фотографии тестов;
- содержимое исходных лабораторных документов;
- локальные вложения чата;
- адреса файлов на устройстве;
- сформированный план, автоматические правила и служебная история помощника;
- серверная телеметрия и административные сведения.

Нужные исходные файлы сохраните отдельно средствами устройства. После передачи через системное меню приложение не управляет созданной копией.

## Экспорт CSV

CSV содержит одну выбранную категорию и подходит для просмотра в табличной программе. Он не заменяет JSON при полном переносе поддерживаемых структурированных записей.

Открывайте CSV как данные, а не как доверенную команду для табличной программы. Не изменяйте заголовки и служебные поля, если файл планируется импортировать обратно.

## Защита экспорта

Архив содержит персональные сведения. Храните его как медицинский документ:

- не прикладывайте к публичной задаче или обычному сообщению поддержки;
- не оставляйте в общей папке без контроля доступа;
- не переименовывайте неизвестный файл в JSON или CSV ради импорта;
- после проверки переноса удалите ненужные временные копии;
- учитывайте резервные копии выбранного облачного диска: удаление локального файла не обязательно удалит их.

## Импорт

1. Создайте свежий экспорт текущих данных.
2. Откройте «Профиль» → «Импорт данных».
3. Выберите архив ArtificialLabs в JSON или поддерживаемый CSV.
4. Проверьте предварительное количество найденных записей.
5. Подтвердите импорт.
6. Откройте профиль, дневник, анализы, сканирования и документы и сравните результат с ожидаемым.

Импорт добавляет или обновляет записи по их идентификаторам и времени изменения. Повторное применение того же файла не предназначено для создания второй независимой копии каждой записи, но после любого повторного импорта результат всё равно нужно проверить.

Остановите импорт, если файл получен из неизвестного источника, предварительное количество неожиданно, формат не распознан или приложение сообщает о повреждённых данных. Не редактируйте медицинские значения вручную внутри архива без понимания формата.

## Отключение синхронизации

Выключение синхронизации прекращает дальнейшую отправку и чтение медицинских данных после обработки отзыва. Если устройство было без сети, приложение завершит отзыв после подключения.

Уже переданные структурированные данные на сервере при этом не удаляются. Для их удаления используется запрос удаления учётной записи. Локальные записи и исходные файлы остаются на устройстве.

## Удаление локальных данных

Команда требует повторного подтверждения и очищает медицинские записи и управляемые файлы ArtificialLabs на текущем устройстве. Перед действием:

1. подготовьте и проверьте экспорт;
2. отдельно сохраните нужные фотографии и документы;
3. выключите уведомления, если больше не хотите получать уже запланированные напоминания;
4. убедитесь, что выбрано правильное устройство и учётная запись.

Локальная очистка не удаляет серверную учётную запись, ранее синхронизированные данные, пользовательские экспорты и копии в других приложениях. Она также не является командой для удалённой очистки потерянного устройства.

## Выход

Выход завершает текущий сеанс. Он не служит удалением данных. На общем устройстве сначала подготовьте резервную копию, затем удалите локальные сведения и только после этого выходите.

При следующем входе другого пользователя приложение не должно показывать записи предыдущей учётной записи. Однако для надёжной очистки принадлежащих приложению исходных файлов на общем устройстве используйте явную команду удаления локальных данных до выхода.

## Удаление учётной записи

Запрос требует подключения к сети. После подтверждения:

1. учётная запись переходит в ожидание удаления;
2. приложение показывает дату окончания 30-дневного периода восстановления;
3. обычная работа с серверными данными блокируется;
4. до указанной даты учётную запись можно восстановить прежними реквизитами;
5. после даты сервер выполняет очистку по расписанию, поэтому она может завершиться не мгновенно в указанную минуту.

Данные текущего устройства очищаются отдельно. Если приложение позднее откроется с сохранённым сроком удаления, оно удалит локальную медицинскую область; до этого момента не считайте устройство очищенным. Экспорты, файлы в других приложениях и резервные копии выбранных хранилищ также остаются под вашим управлением.

Если запрос отклонён из-за административной роли, другой действующий администратор должен сначала отозвать это полномочие. Не пытайтесь обходить ограничение удалением приложения.

## Проверка результата

После переноса или удаления убедитесь, что:

- нужные разделы на новом устройстве содержат ожидаемые записи;
- исходные файлы открываются из выбранного места хранения;
- старое устройство больше не показывает медицинские данные;
- синхронизация имеет ожидаемое состояние на каждом устройстве;
- ненужные временные архивы удалены;
- при удалении аккаунта отображается правильная дата восстановления или подтверждение завершённой очистки.

Не отправляйте поддержке сам архив, фотографию теста, документ, пароль или токен. Для диагностики достаточно версии приложения, платформы, времени действия и безопасного описания результата.
