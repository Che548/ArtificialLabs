# Аккаунт контакты и восстановление

Новый аккаунт создаётся через email. Обычный вход использует пароль и email либо подтверждённый телефон. Проверка телефона и вход только по одноразовому коду — разные функции; штатный вход по телефону требует пароль.

Для восстановления доступны SMS и email, если соответствующий канал настроен. Код состоит из шести цифр. Система ограничивает повторные отправки; количество оставшихся попыток не показывается. Ошибка ограничения не должна приводить к новой отправке сообщения.

Изменение подтверждённого телефона требует текущего пароля и кода на новый номер. Изменение email выполняется отдельным подтверждаемым сценарием. Смена контакта может завершить другие сессии; она не создаёт новый профиль и не даёт новых согласий на обработку данных.

Если код не приходит, проверьте выбранный канал и подождите показанный интервал. Не отправляйте коды в поддержку. Удаление аккаунта имеет 30-дневное окно восстановления; отменить запрос можно, пока аккаунт ещё существует и сервер принимает восстановление.
