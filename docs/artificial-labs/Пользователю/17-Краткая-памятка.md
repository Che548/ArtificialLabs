# Краткая памятка

Список содержит минимальную последовательность действий для безопасной работы с приложением.

## Первый запуск

- [ ] Войти в существующую учётную запись или зарегистрировать новую.
- [ ] Выбрать программу планирования или наблюдения беременности.
- [ ] Заполнить только необходимые сведения профиля.
- [ ] Разрешить камеру, если требуется сканирование.
- [ ] Разрешить уведомления, если нужны локальные напоминания.
- [ ] Отдельно решить, нужна ли облачная синхронизация на этом устройстве.

## Ежедневная запись

- [ ] Выбрать правильную дату.
- [ ] Указать самочувствие, симптомы и нужные измерения.
- [ ] Сохранить запись.
- [ ] Убедиться, что запись появилась в списке.
- [ ] При включённой синхронизации проверить её состояние позднее.

## Сканирование теста

- [ ] Подготовить ровное освещение без бликов.
- [ ] Поместить тест целиком в кадр.
- [ ] Проверить резкость и найденные границы.
- [ ] Прочитать предупреждения о качестве.
- [ ] Подтвердить или исправить результат вручную.
- [ ] Не использовать результат как диагноз.

## Анализ или документ

- [ ] Перенести показатель, единицу и дату из источника.
- [ ] При необходимости прикрепить локальный файл.
- [ ] Проверить сохранённые значения.
- [ ] Помнить, что исходный файл не переносится облачной синхронизацией.

## Перед сменой или очисткой устройства

- [ ] Дождаться завершения разрешённой синхронизации.
- [ ] Создать JSON-экспорт.
- [ ] Отдельно сохранить исходные изображения и документы.
- [ ] Проверить открытие резервных файлов.
- [ ] Только после проверки удалять приложение или данные.

> [!warning]
> Облачная синхронизация не является полной резервной копией устройства.

## При неисправности

Не переустанавливайте приложение до проверки локальных данных. Перейдите к [[Пользователю/18-Диагностика-по-сценарию|диагностике по признаку]] и подготовьте безопасное описание без паролей и медицинских файлов.
