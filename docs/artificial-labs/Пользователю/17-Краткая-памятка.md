# Краткая памятка

1. Проверьте цель профиля и нужную дату перед вводом записи.
2. Дождитесь локального сохранения; сетевой статус оценивайте отдельно.
3. При импорте документа проверьте оригинал, выбранные строки, единицы и дату.
4. Используйте чат для вопросов, ленту помощника — для наступивших напоминаний.
5. Включайте облачные функции осознанно по их получателю и составу данных.
6. Перед переносом сохраните структурированный экспорт и нужные оригиналы отдельно.
7. При сбое передайте поддержке безопасный код и версию приложения.

Уведомление, ответ модели и подтверждение локального сохранения обозначают разные события. Повторный вход не означает новое согласие; переустановка не является обычным способом исправления сети. Проверяйте фактический результат операции перед повтором.
