# Разрешения устройства и облачных функций

Разрешение операционной системы открывает конкретную возможность телефона. Оно не заменяет согласие на передачу данных серверу или внешнему поставщику.

| Разрешение или настройка | Что разрешает |
|---|---|
| Выбор документа | Получить выбранный вами локальный файл |
| Уведомления ОС | Показывать системные напоминания |
| Облачная синхронизация | Передавать поддерживаемые структурированные данные |
| Ответы чата | Выполнять разрешённый диалог с внешним ИИ |
| Автоматические рекомендации | Пересматривать план в пределах разрешённого режима |
| Обработка документов | Передавать страницы для извлечения текста |
| Объяснение текста | Отправить выбранный и просмотренный фрагмент |
| Техническая аналитика | Принимать ограниченные технические события |

При включении нового назначения прочитайте получателя и состав данных. Повторный вход не должен молча воспроизводить старый регистрационный выбор. Отзыв выполняется в настройках соответствующей функции. Уже отправленный запрос не возвращается из сети, но его поздний результат не должен применяться после утраты разрешения.
