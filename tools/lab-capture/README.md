# Lab Capture

Локальный сервер для съёмки тест-полосок с iPhone и Android и для параллельных трёхминутных таймеров. Интернет, внешняя база данных и облачное хранилище не используются.

## Запуск

Mac и телефоны должны находиться в одной локальной сети.

```bash
cd /Users/aleksandrcekmarev/Desktop/ArtificialLabs_RBi/PrivateExpo
npm run lab-capture
```

Сервер выведет доступные адреса, например:

```text
http://192.168.1.25:8787
```

Откройте этот адрес на каждом телефоне. При первом входе выберите `iPhone` или `Android` и задайте понятное имя устройства. Настройка и последняя концентрация сохраняются в браузере телефона.

Остановить сервер: `Control-C` в Terminal. При первом запуске macOS может запросить разрешение принимать входящие соединения.

## Фотографии

После выбора концентрации `2500`, `250`, `25`, `0` или режима `Без полоски` кнопка съёмки открывает системную камеру. Снимок автоматически отправляется на Mac. Если связь оборвалась, файл остаётся в локальной очереди браузера и повторно отправляется после восстановления соединения или по кнопке «Повторить».

Файлы находятся здесь:

```text
tools/lab-capture/data/photos/iPhone/YYYY-MM-DD/2500/
tools/lab-capture/data/photos/Android/YYYY-MM-DD/250/
tools/lab-capture/data/photos/iPhone/YYYY-MM-DD/background/
```

Каталог `data/` исключён из Git. Фотографии не доступны через HTTP; веб-страница показывает только метаданные последних загрузок.

На экране съёмки отображается общее количество реальных файлов во всех папках `iPhone`, `Android`, концентрациях и `background`. При запуске сервер пересчитывает его по содержимому каталога фотографий.

Имена устройств и файлов передаются серверу в URL-кодировке, поэтому кириллица поддерживается безопасно.

## Таймеры

- Нажатие пробела создаёт новый независимый таймер на 3 минуты.
- Кнопка «Новый таймер» делает то же самое на сенсорном устройстве.
- Все открытые страницы синхронизируются через сервер.
- Завершение сопровождается визуальным состоянием и звуковым сигналом, если браузер разрешил воспроизведение звука.
- Состояние хранится в `tools/lab-capture/data/state.json` и восстанавливается после перезапуска.

## Настройки запуска

```bash
HOST=0.0.0.0 PORT=8787 LAB_CAPTURE_DATA_DIR=/absolute/path npm run lab-capture
```

- `HOST` — сетевой интерфейс, по умолчанию `0.0.0.0`.
- `PORT` — порт, по умолчанию `8787`.
- `LAB_CAPTURE_DATA_DIR` — необязательный отдельный каталог фотографий и состояния.

## Проверка

```bash
npm run test:lab-capture
npm run test:lab-capture:browser
```

Первый тест проверяет API, конкурентное сохранение, допустимые форматы, защиту путей, SSE и восстановление состояния. Второй запускает Chromium, проходит первичную настройку, имитирует обрыв загрузки, повторяет её и проверяет несколько таймеров.

## Ограничение доступа

Авторизации нет. Любой человек в той же сети, знающий адрес Mac, сможет открыть страницу и отправить изображение. Не пробрасывайте порт `8787` в интернет и не запускайте сервер в недоверенной публичной сети.
