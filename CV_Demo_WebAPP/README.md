# Сфера Scan — CV Demo WebAPP

Изолированная Next.js веб-версия flow сканирования из мобильного приложения. Создана в `main`; не подключена к существующему развёртыванию `admin/` и не меняет Expo web.

## Локальный запуск

Node.js 22+, CMake, OpenCV (core, imgproc, imgcodecs, calib3d/geometry), C++17.

```sh
# Из корня PrivateExpo
npm ci --prefix CV_Demo_WebAPP
npm run build:cv --prefix CV_Demo_WebAPP
npm run dev --prefix CV_Demo_WebAPP
```

Открыть `http://127.0.0.1:3040`. Данные администратора согласованы отдельно; проверка хранится только на сервере (`lib/auth.ts`, scrypt hash). Пароль в клиентский bundle не входит. Для сборки на macOS: `brew install cmake opencv`. На Debian: `apt-get install cmake g++ libopencv-dev`.

Для production-режима: `npm run build --prefix CV_Demo_WebAPP`, затем `npm run start --prefix CV_Demo_WebAPP`. Для публичного адреса задайте `CV_DEMO_PUBLIC_ORIGIN=https://...`, проксируйте на порт 3040 и используйте HTTPS. Камера работает на HTTPS или localhost. Приложение должно работать одним Node-процессом, без нескольких реплик; для нескольких реплик требуется заменить файловое хранилище доступа на транзакционную БД.

## Что работает

- Модалка входа, серверная HTTP-only сессия, выход и ограничение числа попыток.
- Пять шагов подготовки с иллюстрациями из приложения и настройкой пропуска.
- QR с камеры либо номер партии / встроенный профиль.
- Камера, переключение камеры, загрузка JPEG/PNG/WebP, предпросмотр и пересъёмка.
- Настоящий C++ StripCV из `modules/strip-cv/native` через CLI, с тем же встроенным профилем и правилами проверки качества.
- Отмена обработки, проверка результата, ручная корректировка четырёх углов и направления с повторным CV-анализом.
- Подтверждение результата пользователем. Невалидные и сомнительные результаты сохраняются только как требующие проверки, без автоматической классификации.
- История в IndexedDB, поиск, фильтры, редактирование, удаление и экспорт JSON.
- Гостевые ссылки на 1 час / сутки / неделю с отзывом; гости не управляют ссылками. Ссылки повторно используемые до истечения срока. Секрет передаётся во fragment и немедленно удаляется из адреса. Сервер хранит только его хеш. Отзыв инвалидирует созданные по ссылке сессии.

## Данные и ограничения

Снимок временно передаётся серверу демо для CV; фотографии и медицинские результаты не пишутся на серверный диск, в логи или Convex. Сохранение истории происходит только в браузере. История не синхронизируется между устройствами; очистка данных сайта удаляет её. Доступ по одному приглашению в одном браузере использует одну локальную историю; это демонстрационный доступ, а не личные медицинские аккаунты.

Состояние доступа (сессии, хеши приглашений, секрет подписи) хранится в `.data/access.json` с правами 0600. Каталог должен быть постоянным и не публиковаться. Для контейнера смонтируйте постоянный каталог и задайте `CV_DEMO_DATA_DIR`. Удаление каталога сбрасывает все сессии и ссылки. Не размещайте эту папку в public и не коммитьте её.

Обработка ограничена двумя одновременными CV-процессами, 30 секундами, 12 МБ на фото и 20 Мп. Браузер нормализует EXIF и уменьшает большую сторону до 2400 пикселей. Никаких внешних AI API и фиктивных CV-результатов. Встроенный профиль не содержит валидированного диагностического порога; распознавание линий не является диагнозом.

## Проверка

```sh
npm run build:cv --prefix CV_Demo_WebAPP
npm run verify --prefix CV_Demo_WebAPP
npm run test:e2e --prefix CV_Demo_WebAPP
npm run verify
```

Unit tests запускают настоящий CLI на синтетических изображениях. Playwright проверяет защищённый вход, инструкции, загрузку, реальный CV-путь для невалидного кадра, корректировку, историю и отзыв гостевого доступа. Скриншоты содержат только синтетические данные и находятся в игнорируемом `test-results/`. Доступ к физической камере и качество реальных тестов требуют отдельной проверки на целевом устройстве.

## Проверено локально

14 сентября 2026: сборка C++ StripCV с OpenCV 5, три CTest-проверки ядра, восемь unit-тестов веб-версии, production-сборка Next.js и общий `npm run verify` репозитория прошли. Для браузерных тестов установите `npx playwright install chromium`; проверка реального входа дополнительно использует серверную переменную `CV_DEMO_TEST_PASSWORD`. Пароль не записывается в тестовые файлы.

Все четыре Playwright-сценария прошли: реальный вход и выход, защита API, инструкции с возвратом к фото, нативный анализ и ручная рамка, история, мобильная вёрстка, гостевой вход и отзыв ссылки.
